# plumbing-3d

Starter files for building plumbing parts with Python and CadQuery.

## Project layout

- `src/plumbing_3d/`: package starter files for reusable plumbing part helpers
- `notebooks/plumbing_part_starter.ipynb`: notebook starter for interactive CadQuery modeling
- `tests/`: focused package scaffold validation

## Quick start

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
```

Install CadQuery in your notebook environment before running the starter notebook.
